# Input image

`observation.jpg` is the original first-person render from the Misalignment rooftop experiment. The environment was authored for the experiment using Three.js. The person uses Adobe Mixamo's **Joe** character, obtained through the public three.ws character catalog.

- Character source: [Adobe Mixamo](https://www.mixamo.com/)
- Usage terms: [Adobe Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)

The repository contains the rendered image, not the underlying character model. Third-party character rights remain with their respective owners and are not relicensed by the repository's MIT license. No real person is depicted.
